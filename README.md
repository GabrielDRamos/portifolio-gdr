# portifolio-gdr

Portfólio pessoal desenvolvido 100% em **Angular 22+** (TypeScript + Tailwind CSS v4, Node.js 26+) com foco em **Mobile-First**.

## Como Rodar Localmente

```bash
cd frontend
npm install
npm start
```

Acesse `http://localhost:4200`.
